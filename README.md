# Sound-Chasing Bot: An Arduino-Based Robotic Learning Path

This roadmap guides you through the process of building a mobile robot that can detect and autonomously move towards loud noises or claps. You will learn fundamental concepts in embedded programming, sensor integration, motor control, and basic robotics hardware assembly, culminating in a functional sound-chasing robot.

📊 **4 Phases** | **20 Tasks**

---

## 🛠️ Tech Stack
- Arduino Nano
- C/C++ (for Arduino IDE)
- Sound Sensor Module (e.g., LM393)
- L298N Motor Driver
- DC Motors with Wheels
- Chassis Kit
- 9V Battery
- Breadboard
- Jumper Wires

## 📋 Requirements
- Robot must detect loud noises/claps.
- Robot must turn towards the detected sound source.
- Robot must move forward for a short duration after turning.
- Robot must operate autonomously without tethered control.
- Components must be securely mounted on a mobile chassis.
- The system must be powered by a portable battery.

## ✅ Acceptance Criteria
- [ ] The robot successfully detects clapping or loud noises.
- [ ] Upon detection, the robot turns its body towards the perceived direction of the sound source.
- [ ] After orienting, the robot moves forward for a short, predefined duration (e.g., 1-2 seconds).
- [ ] The robot can continuously repeat the detect-turn-move cycle, effectively 'chasing' the sound.
- [ ] The robot demonstrates stable movement on a flat surface without tipping or getting stuck.
- [ ] All electronic components are securely mounted and properly wired.
- [ ] The robot operates autonomously using a battery power source.
